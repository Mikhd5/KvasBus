# KvasBus Website

Адаптивний односторінковий сайт пасажирського перевізника KvasBus.

## Запуск локально

1. Розпакуйте `kvasbus-website.zip`.
2. Відкрийте `index.html` у сучасному браузері.
3. Для локального сервера можна виконати в цій папці: `python -m http.server 8000` і відкрити `http://localhost:8000`.

## Структура

- `index.html` — сторінка, стилі та клієнтська логіка.
- `hero-sprinter.webp` — головне зображення.
- `fleet-sprinters.webp` — зображення мікроавтобусів.
- `sprinter-interior.webp` — зображення салону.
- `prague-scenic.webp` — панорама Праги.

## Форма бронювання

Форма перевіряє обов'язкові поля та формує повідомлення з деталями поїздки, після чого відкриває WhatsApp на номері перевізника. Повідомлення користувач відправляє самостійно; серверна CRM або автоматичне надсилання не підключені.

## Зображення

Усі чотири зображення в корені репозиторію згенеровані для візуального концепту й локально збережені в архіві. Вони є ілюстративними, а не документальними фотографіями реального автопарку KvasBus.
